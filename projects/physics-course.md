# Physics II Interactive Course

## Problem

University-level physics material should be accessible through a browser and available for study without a continuous internet connection.

## Delivery

The course is published under Turin Prepnik. Its distribution documentation provides an online course, an offline ZIP for computers, and an optional Android APK. Updates use GitHub releases, with an update notice in the website.

A separate collector handles voluntary feedback; the public course repository excludes feedback responses and administration credentials.
