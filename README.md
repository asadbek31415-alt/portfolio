## Selected projects

### Prepnik Records — purchase tracking and Telegram administration

A private records application with a phone-friendly dashboard and an owner-only Telegram bot. It tracks course purchases, payments, deferred payments, refunds, and changes to records.

- Keeps payment dates separate from purchase dates so reports reflect when money actually moved.
- Preserves unknown prices rather than treating them as zero revenue.
- Uses integer currency amounts and prevents duplicate purchase confirmations.
- Includes reminders, audit history, Excel exports, and database backups.

**Stack:** JavaScript, Node.js, Express, SQLite, Telegram Bot API, ExcelJS.

[Project case study](projects/prepnik-records.md) · Source and operational records remain private.

### Algorithm & Programming I — Telegram course Mini App

A course application combining learning material, Telegram access verification, and a C programming practice interface.

- Organizes theory, practice, code exercises, and installation material in one interface.
- Serves protected course content after Telegram Mini App verification.
- Provides a server endpoint for running C code through Judge0 and showing compiler output.
- Supports bot administration for access management and announcements.

**Stack:** Next.js, React, TypeScript, Telegraf, SQLite via sql.js, Judge0.

[Project case study](projects/programming-course.md) · Source and protected course material remain private.

### Physics II — interactive university course

An interactive university-level Physics II course published under Turin Prepnik, with online access and offline distribution options.

- Available in a browser on computers, tablets, and phones.
- Distributed as an offline computer ZIP and an optional Android APK.
- Includes release-based updates and a separate voluntary feedback collector.
